# Tableau Dashboard Specifications - Financial Trade Anomaly Detection

This document provides a step-by-step guide for constructing an interactive, production-ready operational dashboard in **Tableau Desktop / Tableau Cloud** using the `tableau_trade_analytics.csv` data extract generated by the Python & SQL backend.

---

## Data Source Connection
1. Open **Tableau Desktop**.
2. Under *To a File*, click **Text File** and select `tableau_trade_analytics.csv`.
3. Set data types:
   - `ExecutionTime` → Date & Time
   - `NotionalValue` → Currency (Standard)
   - `Price` → Currency (Standard / 4 decimal places)
   - `AnomalyRiskScore` → Number (Decimal)
   - `IsAnomaly` → Dimension (Boolean / Integer)

---

## Calculated Fields to Add in Tableau

```tableau
// 1. Critical Anomaly Flag
[Is Critical] : IF [RiskTier] = 'CRITICAL' THEN 1 ELSE 0 END

// 2. Risk Color Code
[Risk Color Palette] : 
IF [RiskTier] = 'CRITICAL' THEN '#9C0006'
ELSEIF [RiskTier] = 'HIGH' THEN '#9C6500'
ELSEIF [RiskTier] = 'MEDIUM' THEN '#FFEB9C'
ELSE '#C6EFCE'
END

// 3. Trade Size Ratio
[Size Ratio vs Avg] : [Quantity] / ([Quantity] / NULLIF([QtyZScore],0))
```

## Dashboard View 1: Operational Executive Overview

### Purpose
High-level operational overview summarizing trade volume, anomaly rates, risk tier distribution, and notional risk exposure across desks.

### Worksheets Layout:
1. **KPI Banner (Top Row)**
   - **Total Trades Monitored**: `CNT([TradeID])`
   - **Total Anomaly Count**: `SUM([IsAnomaly])`
   - **Anomaly Rate (%)**: `SUM([IsAnomaly]) / CNT([TradeID])` (Format as percentage `0.0%`)
   - **Total Risk Exposure ($)**: `SUM(IF [IsAnomaly]=1 THEN [NotionalValue] END)`

2. **Risk Tier Breakdown (Donut / Bar Chart)**
   - Dimensions: `RiskTier`
   - Measures: `CNT([TradeID])`, `SUM([NotionalValue])`
   - Color: `[Risk Color Palette]`

3. **Time-Series Anomaly Burst Detector (Line Chart)**
   - Columns: `ExecutionTime` (Minute / Hour granularity)
   - Rows: `CNT([TradeID])` and `SUM([IsAnomaly])` dual-axis
   - Marks: Highlight spikes in orange/red where `[IsAnomaly]` exceeds normal thresholds.

---

## Dashboard View 2: Counterparty Concentration & Risk Heatmap

### Purpose
Identify systemic risk and counterparty concentration spikes in real-time.

### Worksheets Layout:
1. **Counterparty vs Desk Heatmap**
   - Columns: `Desk`
   - Rows: `Counterparty`
   - Color Mark: `MAX([CP_1H_TradeCount])` or `SUM([IsConcentrationAnomaly])`
   - Color Gradient: Red-Yellow Diverging

2. **Top 5 Exposure Counterparties (Horizontal Bar Chart)**
   - Rows: `Counterparty`
   - Columns: `SUM([NotionalValue])`
   - Detail Tooltip: Breakdown of Size, Price, and Concentration Anomaly Counts.

---

## Dashboard View 3: Trade Lifecycle Anomaly Scatter Deep-Dive

### Purpose
Interactive scatter plot allowing middle-office analysts to explore multivariate trade distributions and isolate specific outliers.

### Worksheets Layout:
1. **Multivariate Anomaly Scatter Plot**
   - Columns: `[PriceDevPct]` (Price Deviation %)
   - Rows: `[QtyZScore]` (Quantity Z-Score)
   - Mark Type: Circle / Shape
   - Detail: `TradeID`, `Trader`, `Counterparty`, `Instrument`
   - Size: `[NotionalValue]`
   - Color: `[AnomalyRiskScore]` (Continuous Red-Gray Gradient)

2. **Interactive Filters & Actions**
   - Filter Actions: Clicking a `Counterparty` or `Desk` filters all deep-dive detail sheets.
   - Hover Tooltips: Show `PrimaryAnomalyReason`, `TimeDiffSeconds`, and `IsolationForestScore`.
